## 1. aerospace 설치
```zsh
brew install --cask nikitabobko/tap/aerospace
```

## 2. i3-like config

`nvim ~/.aerospace.toml`을 [default-confg](https://github.com/nikitabobko/AeroSpace/blob/main/docs/config-examples/default-config.toml)로 수정
- 설정 파일의 위치는 https://nikitabobko.github.io/AeroSpace/guide#config-location 참고
