# Ktor Setup (1): Ktor Project Generator로 프로젝트 생성

[Ktor project generator](https://start.ktor.io/settings)에서 다음과 같이 진행
1. **Project artifact** 필드 채우기
2. **Configure** 에서 다음 선택
	- Build system: Gradle Kotlin
	- Engine: Netty
	- Configuration: HOCON File
3. **Download**

[Use the Ktor project generator](https://ktor.io/docs/server-create-a-new-project.html#create-project-with-the-ktor-project-generator) 참고

이후 프로젝트를 원하는 경로에 다운로드 하고 압축을 풀자
- 프로젝트 루트
