## Install SDK

### 1. Download the latest version of the Airbridge Unity SDK.

[Airbridge Unity SDK](https://sdk-download.airbridge.io/unity/index.html?latest).

### 2. Import the *Airbridge Unity SDK Package* into Unity

> Select **[Assets]>[Import Package]>[Custom Package ...]** in Unity and add the downloaded package file.
>    
> [Install SDK](https://help.airbridge.io/en/developers/unity-sdk-v4#install-sdk)

![[Pasted image 20260205191502.png]]

> [!NOTE] *EDM4U* 가 이미 설치되어 있다면, 제외하고 import 하자.

> Once the package is added to Unity, the **[Airbridge]** tab will appear in the top menu bar.
> 
> [Install SDK](https://help.airbridge.io/en/developers/unity-sdk-v4#install-sdk)

![[화면 캡처 2026-01-23 142758.png]]

## Initialize SDK

> Enter the correct App Name and App Token values in the [SDK Settings](https://help.airbridge.io/en/developers/unity-sdk-v4#configure-sdk-settings) window. The App Name and App Token can be found on the **[Settings]>[Tokens]** page in the Airbridge dashboard.
> 
> [Initialize SDK](https://help.airbridge.io/en/developers/unity-sdk-v4#initialize-sdk)

> [!NOTE] [Add Your App to Airbridge](https://help.airbridge.io/en/guides/register-a-new-app) 과정을 반드시 미리 완료해야 한다.

![[화면 캡처 2026-02-05 193034.png]]

## Configure SDK settings

> Select **[Airbridge]>[Airbridge Settings]** from the top menu bar in Unity to open the SDK settings window. You may fill in the fields or click on the checkboxes that are necessary for your service.
> 
> [Configure SDK settings](https://help.airbridge.io/en/developers/unity-sdk-v4#configure-sdk-settings)

필요한 설정 값을 넣으면 된다.
