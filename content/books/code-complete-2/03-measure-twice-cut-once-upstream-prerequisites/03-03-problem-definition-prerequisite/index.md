# 3.3 문제 정의 선행 조건

> [!quote]
> 
> 구현에 들어가기에 앞서 완료해야 하는 첫 번째 선행 조건은 시스템이 해결해야 하는 문제를 명확하게 기술하는 것이다.

문제 정의는 반드시 사용자의 언어로 작성
- 사용자 관점
- 컴퓨터 전문 용어로 작성하면 안 됨
