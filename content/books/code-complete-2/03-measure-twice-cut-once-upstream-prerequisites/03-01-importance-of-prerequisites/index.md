# 3.1 선행 조건의 중요성

## 선행 조건의 중요성

> [!quote]
>
> 폰티악 아즈텍의 설계 작업을 시작한다면 원하는 모든 것을 테스트한다고 하더라도 결코 롤스로이크가 되지는 않을 것이다.

**선행 조건(prerequisites)** 은 구현을 시작하기 전에 갖춰져야 하는 준비 작업과 결정 사항임. ^prerequisites

## 불완전한 준비의 원인

선행 작업에 투입되는 개발자가 자신의 작업을 수행할 수 있을 정도의 전문가적인 지식을 갖고 있지 않다는 점

관리자가 선행 조건을 수행하기 위해서 시간을 투자하는 개발자들을 못마땅하게 봄

## 구현 전에 선행 조건을 수행하기 위한 필수적인 논의

아래 근거로 관리자를 설득하라

### 논리적 설득

관리 측면
- 시간, 인력, 장비의 수 결정

기술적 측면
- 돈 낭비 X
- 무엇을 만드는지 정확히 이해하기

### 비유적 설득

skip

### 데이터에 근거한 설득

구현 초기에 결함을 제거하면 비용이 100분의 1정도 까지 줄어듬
