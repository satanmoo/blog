# 3.5 아키텍처 선행 조건

**아키텍처**도 선행 조건에 포함
- 아키텍처의 품질이 시스템의 개념적인 무결성을 결정
	- 품질 결정
- 좋은 아키텍처는 구현을 쉽게 만듬
- ==아키텍처의 오류 수정은 요구사항 오류를 수정할 때 함께 진행==
