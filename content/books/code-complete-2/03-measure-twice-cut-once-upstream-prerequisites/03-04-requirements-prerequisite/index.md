# 3.4 요구사항 선행 조건

> [!quote] requirements
>
> 요구사항은 소프트웨어 시스템이 무엇을 수행해야 하는지에 대해 상세하게 기술한다.

**요구사항(requirements)** 은 소프트웨어가 수행해야 할 일을 구체적으로 정의하는 기준임. ^requirements

*요구사항*은 해결책을 구현하기 전에 먼저 수행해야 하는 작업임.

이 절에서 말하는 *요구사항* 작업은 다음 표현들과 연결됨.

- 요구사항 개발
- 요구사항 분석
- 요구사항 정의
- 소프트웨어 요구사항
- 명세화
- 기능 명세
- 명세

핵심은 구현 전에 소프트웨어가 ==무엇을 해야 하는지==를 충분히 구체화하는 것임.
