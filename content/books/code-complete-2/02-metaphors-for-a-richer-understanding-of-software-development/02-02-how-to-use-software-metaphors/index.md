# 2.2 소프트웨어 비유 사용법

## 소프트웨어 비유 사용법

> [!quote] 그렇다면 소프트웨어 비유를 어떻게 사용할 것인가? 그것을 프로그래밍 문제와 프로세스를 이해하는 데 활용하라.

소프트웨어 비유는 코드 한 줄이 특정 비유와 정확히 맞는지 판정하는 도구가 아님

목적은 더 나은 프로그래밍 작업 방식을 떠올리는 것
- 비유를 활용하면 코드를 더 빨리 작성할 수 있다는 것이 저자의 생각
