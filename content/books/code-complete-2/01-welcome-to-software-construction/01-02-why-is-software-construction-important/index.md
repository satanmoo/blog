# 1.2 소프트웨어 구현이 중요한 이유는 무엇인가?

## 소프트웨어 구현이 중요한 이유는 무엇인가?


> [!quote] source code
>
> 소스코드는 항상 최고의 품질을 유지해야 한다.

**소스코드(source code)** 는 많은 프로젝트에서 소프트웨어를 가장 정확하게 설명하는 산출물임. ^source-code

요구사항 명세서나 설계 문서는 최신 상태를 잃을 수 있지만, 실제 동작하는 시스템의 현재 상태는 결국 *소스코드*에 반영됨.

따라서 *구현* 품질은 단순히 개발자의 취향 문제가 아니라, 프로젝트가 유지할 수 있는 유일한 정확한 문서의 품질 문제임.
