# 1.1 소프트웨어 구현이란 무엇인가?

## 소프트웨어 구현이란 무엇인가?

> [!quote] construction
>
> 대개 "구현"이라고 하면 뭔가를 만드는 실질적 작업을 의미한다.

**구현(construction)** 은 소프트웨어 개발에서 실제로 동작하는 산출물을 만드는 중심 활동임. ^construction

건축에서 *construction*이 집이나 건물을 짓는 일을 가리키듯, 소프트웨어에서 *구현*은 계획과 설계를 바탕으로 실행 가능한 소프트웨어를 만들어가는 활동임.

대부분 **개발 과정(development process)** 에는 다음과 같은 활동이 포함됨. ^development-process

- 문제 정의
- 요구사항 개발
- 구현 계획 수립
- 아키텍처/고급 수준 설계
- 상세 설계
- 코드 작성 및 디버깅
- 단위 테스트
- 통합 테스트
- 통합
- 시스템 테스트
- 유지보수

이 목록은 *구현*이 전체 *개발 과정*의 한 부분이면서도 여러 활동과 겹쳐 있음을 보여줌.

**코드 작성(coding)** 과 **디버깅(debugging)** 은 좁은 의미의 *구현*임.

넓은 의미의 *구현*에는 다음 활동도 포함됨.

- 상세 설계
- 구현 계획 수립
- 단위 테스트
- 통합 테스트
- 통합

> [!principle] 절차의 균형
>
> 소프트웨어 개발에는 절차가 필요하지만, *구현* 활동은 절차의 모자람과 지나침 사이에서 균형을 맞추는 일임.
